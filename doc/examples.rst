########
Overview
########

Vibrations is a Python code for vibrational calculations with
user-defined vibrational modes. For an overview of the capabilities
of the code, see the following articles

[ChemPhysChem 15 (2014) 3365] (http://dx.doi.org/10.1002/cphc.201402251),

[J. Chem. Phys. 144 (2016) 164111] (http://dx.doi.org/10.1063/1.4947213),

[J. Phys. Chem. Lett. 7 (2016) 3084] (http://dx.doi.org/10.1021/acs.jpclett.6b01451).


See `/vibrations/examples/` directory for some examples of typical runs.


.. code-block:: console

   /vibrations/examples/
            ├── 1.Existing_potentials/ 
            ├── 2.Localized_modes_harmonic/
            ├── 3.Localized_modes_anharmonic/
            ├── 4.StepByStep_H2O_NM/
            └── 5.StepByStep_H2O_LM/

As a typical example of a vibrational spectra calculation in terms of localized modes, we take the results of an **SNF** calculation (https://reiher.ethz.ch/software/snf.html) of an *Ala10* or a water molecule (harmonic approximation).
